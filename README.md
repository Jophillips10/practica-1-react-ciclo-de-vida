## Descripción del Proyecto
Esta aplicación web desarrollada en React (con Vite) demuestra de manera práctica:
1. **El ciclo de vida de un componente:** Montaje, Actualización y Desmontaje usando React Hooks (`useEffect`).
2. **Los estados de carga de una petición asíncrona:** Estado inicial, Cargando (Spinner / Skeleton), Datos cargados con éxito, Sin resultados, Error y Mecanismo de reintento/recarga.
